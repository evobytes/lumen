# Web API reference

GENERATED by `scripts/docgen` from the route table in `internal/api` (`api.Routes`). Do not
edit by hand: change the route's summary in the code and run `make docs`.

The server listens on `server.listen` (default `127.0.0.1:8765`). Routes under `/api/v1` need the
`auth.token` secret as `X-API-Token` or `Authorization: Bearer` when one is configured (the event
stream also accepts `?token=`, because browsers cannot set headers on `EventSource`). Errors are
`application/problem+json`. Request bodies are bounded JSON and unknown fields are rejected.

| Method | Path | Auth | Description |
|---|---|---|---|
| `GET` | `/healthz` | no | liveness probe; always 200 ok |
| `GET` | `/{$}` | no | redirect to the control page |
| `GET` | `/control` | no | control page (HTML) |
| `GET` | `/output` | no | output page (HTML); ?debug adds an overlay, ?probe runs the media probe |
| `GET` | `/assets/{file...}` | no | static CSS and JavaScript for the pages |
| `GET` | `/media/{file...}` | no | self-test media clips (only when the self-test is running) |
| `GET` | `/api/v1/version` | token | build version, commit and build stamp |
| `GET` | `/api/v1/status` | token | position, blank flag, current slide and all slides |
| `POST` | `/api/v1/next` | token | advance one slide (stops at the last) |
| `POST` | `/api/v1/prev` | token | go back one slide (stops at the first) |
| `POST` | `/api/v1/slides/{index}/show` | token | show slide {index}; 404 if it does not exist |
| `PUT` | `/api/v1/slides` | token | replace all slides: {"slides":[{"title":"","text":"..."}]} |
| `POST` | `/api/v1/blank` | token | blank {"blank":true}, unblank {"blank":false}, or toggle with an empty body |
| `GET` | `/api/v1/screens` | token | connected monitors as the OS reports them |
| `PUT` | `/api/v1/output` | token | move the output: {"screen":"<id>","placement":"win32\|toolkit"} or {"screen":null} for the floating window |
| `GET` | `/api/v1/windows` | token | both windows as the OS reports them (rectangles, topmost, owner, DPI, monitor) |
| `GET` | `/api/v1/events` | token | server-sent events: an event named state after every change (token may be ?token=) |
| `POST` | `/api/v1/report/{name}` | token | store a diagnostics JSON document (used by the self-test) |
| `GET` | `/api/v1/report` | token | read all stored diagnostics documents |

```sh
curl -X POST http://127.0.0.1:8765/api/v1/next
curl -X PUT  http://127.0.0.1:8765/api/v1/slides -H 'content-type: application/json' \
     -d '{"slides":[{"text":"Hello"},{"text":"World"}]}'
curl -X PUT  http://127.0.0.1:8765/api/v1/output -d '{"screen":"\\\\.\\DISPLAY2"}'
```
